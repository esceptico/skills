# Agent skills

[![skills.sh](https://skills.sh/b/esceptico/skills)](https://skills.sh/esceptico/skills)

Reusable agent skills maintained by [esceptico](https://github.com/esceptico).

## Skills

### development-ledger

Create and maintain an evidence-backed development ledger from original intent through research, synthesis, decisions, implementation planning, and verification. The generated ledger is split into compact lifecycle files for reliable re-entry after context compaction or handoff.

Install with the skills CLI:

```bash
npx skills add esceptico/skills --skill development-ledger -g -y
```

Or invoke it after installation:

```text
Use $development-ledger to research and scope this task before implementation.
```
