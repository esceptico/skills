# Agent skills

[![skills.sh](https://skills.sh/b/esceptico/skills)](https://skills.sh/esceptico/skills)

Reusable agent skills maintained by [esceptico](https://github.com/esceptico).

## Skills

### development-ledger

Create and maintain an evidence-backed development ledger from original intent through research, synthesis, decisions, implementation planning, and verification.

```bash
npx skills add esceptico/skills --skill development-ledger -g -y
```

### tool-harness-audit

Audit MCP and agent tool harnesses for agent ergonomics, reliability, mutation safety, recovery, and evaluation quality.

```bash
npx skills add esceptico/skills --skill tool-harness-audit -g -y
```
